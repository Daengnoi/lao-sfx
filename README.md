# Lao Manga SFX Generator (ຕົວອັກສອນສຽງມັງງະ)

Single-file, browser-only tool. Type a Lao sound word, style it, export PNG / SVG / PDF / PSD.
No build step, no server, nothing is uploaded.

## Publish with GitHub Pages
1. Create a new repository (e.g. `lao-sfx`).
2. Upload `index.html` and `README.md` to the repository root.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. Open `https://<your-username>.github.io/lao-sfx/` after about a minute.

## Fonts
Built-in: Noto Sans Lao, Noto Serif Lao, Noto Sans Lao Looped (Google Fonts, loaded online).
Add your own with the upload button (.woff2 .ttf .otf). Only use fonts you are licensed to use.
